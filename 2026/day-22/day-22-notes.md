What is the difference between git add and git commit?<br>
ANS- git add add the untracked files to the staging area and git commits the file into git repository.<br><br>
What does the staging area do? Why doesn't Git just commit directly?<br>
ANS:-the staging area pick up the file which you want to final commit. this area lets us review the files before letting final commit.Staging area let us compare the changes that we made. If we commit directly we couldn't compare and the faulty bug can be commited which we don't want to commit.<br><br>
What information does git log show you?<br>
ANS:- Git log shows the history of commits. In git log we can see commit ID, commit message, date commited and autor details.<br><br>
What is the .git/ folder and what happens if you delete it?<br>
ANS:- git folder contain all the versions, logs history, information related to branches etc. When we delete it we delete the git repo and all the version control is deleted and you cannot access the history and log of git repo.<br><br>
What is the difference between a working directory, staging area, and repository?<br>
ANS:- working directory is local file directory where the changes are not being tracked.
staging area is the area where you can track the changes you have made. repository is directory where the versions of code is stored.
